# Fuel Station Dashboard (MVP)

## Overview

This is a simple fuel station dashboard that tracks fuel stock, estimated sales, and profit using dipstick readings.

## Features

* Convert dipstick height (ft) to litres
* Track opening and closing stock
* Record fuel deliveries
* Estimate litres sold
* Calculate revenue and profit
* Store history using localStorage

## TechStack Used

* HTML
* CSS
* JavaScript

## Notes

* Tank is rectangular
* Data is stored in browser (localStorage)
